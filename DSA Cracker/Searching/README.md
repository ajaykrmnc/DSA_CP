# Searching

Most searching problems are binary search, boundary search, or answer search. Problem files live in pattern folders.

## Pattern Map

| Pattern | Matching signal | Problems |
|---|---|---|

| Binary search on sorted array | Need floor, count ones, square root, sorted lookup | [Floor in a Sorted Array](<Binary search on sorted array/Floor in a Sorted Array.md>), [Count 1's in binary array](<Binary search on sorted array/Count 1's in binary array.md>), [Square root of a number](<Binary search on sorted array/Square root of a number.md>), [Searching an element in a sorted array](<Binary search on sorted array/Searching an element in a sorted array.md>) |

## Pattern Matches

1. **Binary search + bounds**: Floor, first index, count ones.
2. **Binary search + feasibility**: Allocate pages.
3. **Searching + prefix/hash**: Subarray sum with exact target.
4. **Searching + two pointers**: Water/building distance and sorted relation problems.
