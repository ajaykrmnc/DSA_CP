# Minimum Difference in an Array

**Problem Statement:**
Given an array of integers, find the minimum absolute difference between any two elements in the array. The straightforward approach is to sort the array first, then find the minimum difference between adjacent elements since the minimum difference will always be between consecutive elements in a sorted array. This approach has O(n log n) time complexity due to sorting and O(1) space complexity. An alternative approach using nested loops has O(n²) time complexity but doesn't require sorting.
