# Sorting

Use sorting when ordering exposes pairs, partitions, inversions, or greedy structure. Problem files live in pattern folders.

## Pattern Map

| Pattern | Matching signal | Problems |
|---|---|---|

| Merge sorted arrays | Need combine sorted sequences | [Merge two sorted arrays](<Merge sorted arrays/Merge two sorted arrays.md>), [Merge 2 Arrray](<Merge sorted arrays/Merge 2 Arrray.md>) |

## Pattern Matches

1. **Sorting + two pointers**: Triplets, triangles, intersections.
2. **Sorting + merge count**: Inversions and reverse pairs.
3. **Sorting + greedy**: Candy and minimum difference.
4. **Sorting + partitioning**: Binary and 0/1/2 array problems.
