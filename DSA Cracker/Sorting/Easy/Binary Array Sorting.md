# Binary Array Sorting

**Problem Statement:**
Given a binary array containing only 0s and 1s, sort the array in ascending order (all 0s followed by all 1s). This can
be solved in multiple ways: counting sort approach (count 0s and 1s, then fill array), two-pointer approach (left
pointer for 0s, right pointer for 1s, swap when needed), or partitioning approach similar to quicksort. The optimal
solution has O(n) time complexity and O(1) space complexity. The two-pointer approach is most intuitive and efficient.
