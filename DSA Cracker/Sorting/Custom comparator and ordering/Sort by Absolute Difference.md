# Sort by Absolute Difference

**Problem Statement:**
Given an array of integers and a target value x, sort the array based on the absolute difference of each element from x. Elements with smaller absolute difference should come first. If two elements have the same absolute difference, maintain their relative order (stable sort). For example, if array is [10, 5, 3, 9, 2] and x = 7, the sorted array should be [5, 9, 10, 3, 2] because |5-7|=2, |9-7|=2, |10-7|=3, |3-7|=4, |2-7|=5. Use custom comparator with stable sorting algorithm.
