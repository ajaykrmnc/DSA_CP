# Count the number of possible triangles

**Problem Statement:**
Given an array of positive integers representing the lengths of line segments, count the number of triangles that can be formed using these segments. For three sides to form a triangle, they must satisfy the triangle inequality: the sum of any two sides must be greater than the third side. Sort the array first, then for each pair of sides (i, j) where i < j, count how many valid third sides exist using binary search or two pointers. The time complexity is O(n²) with sorting.
