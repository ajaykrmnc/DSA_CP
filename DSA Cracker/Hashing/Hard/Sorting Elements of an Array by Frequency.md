# Sorting Elements of an Array by Frequency

**Problem Statement:**
Given an array of integers, sort the elements based on their frequency of occurrence. Elements with higher frequency should appear first. If two elements have the same frequency, maintain their relative order (stable sort) or sort them by value as specified. Use a hash map to count frequencies, then sort based on frequency counts. This problem combines hashing for frequency counting with custom sorting logic. The time complexity is O(n log n) due to sorting, and space complexity is O(n) for the frequency map.
