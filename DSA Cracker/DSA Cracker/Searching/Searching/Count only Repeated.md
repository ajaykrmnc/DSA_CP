# Count only Repeated

**Problem Statement:**
Given an array of integers, count the number of elements that appear more than once in the array. Use a hash map or hash set to track the frequency of each element. Iterate through the array once to count frequencies, then iterate through the frequency map to count how many elements have frequency greater than 1. Alternatively, use a set to track seen elements and another set to track repeated elements. The time complexity is O(n) and space complexity is O(n) for the hash-based approach.
