# Positive Negative Pair

**Problem Statement:**
Given an array of distinct integers, find all the pairs having both negative and positive values of a number in the array. For each number x in the array, check if -x also exists in the array. If both x and -x exist, they form a positive-negative pair. Use a hash set to store all numbers and then iterate through the array to find pairs. Print the pairs in ascending order of their absolute values. This problem demonstrates efficient use of hashing for pair finding with O(n) time complexity.
