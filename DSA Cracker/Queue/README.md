# Queue

Use queue patterns for FIFO simulation, BFS-style generation, and two-stack/two-queue conversions. Problem files live in pattern folders.

## Pattern Map

| Pattern | Matching signal | Problems |
|---|---|---|
| Queue implementation | Build queue with array or linked list | [Implement Queue using array](<Queue implementation/Implement Queue using array.md>), [Implement Queue using Linked List](<Queue implementation/Implement Queue using Linked List.md>), [Operations on Queue](<Queue implementation/Operations on Queue.md>) |
| Stack/queue conversion | Implement one structure using the other | [Stack using two queues](<Stack and queue conversion/Stack using two queues.md>), [Queue using two Stacks](<Stack and queue conversion/Queue using two Stacks.md>) |
| Queue reversal | Reverse full queue or first K elements | [Queue Reversal](<Queue reversal/Queue Reversal.md>), [Reverse First K elements of Queue](<Queue reversal/Reverse First K elements of Queue.md>) |
| BFS-style generation | Generate values level by level | [Generate Binary Numbers](<BFS-style generation/Generate Binary Numbers.md>) |
| Circular greedy queue | Need starting point in a cycle | [Circular tour](<Circular greedy queue/Circular tour.md>) |

## Pattern Matches

1. **Queue + stack**: Reversal and queue-from-stacks.
2. **Queue + BFS**: Binary number generation.
3. **Queue + greedy**: Circular tour start index.
