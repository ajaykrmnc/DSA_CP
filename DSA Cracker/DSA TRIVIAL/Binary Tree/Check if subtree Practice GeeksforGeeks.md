# Check if subtree | Practice | GeeksforGeeks

**Problem Statement:**
Given two binary trees with head references as T and S having at most N nodes, check if S is present as a subtree in T.
A subtree of a tree T1 is a tree T2 consisting of a node in T1 and all of its descendants in T1. The task is to
determine if the entire structure and values of tree S match exactly with some subtree of tree T. This problem
requires comparing tree structures recursively and can be solved using tree traversal techniques to find matching
nodes and then verify if the complete subtree matches.
