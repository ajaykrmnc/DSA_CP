# Traversal

**Problem Statement:**
Binary tree traversal involves visiting all nodes in a tree in a specific order. The three main traversal methods are: Inorder (Left-Root-Right), Preorder (Root-Left-Right), and Postorder (Left-Right-Root). Each traversal has specific use cases - inorder gives sorted sequence for BST, preorder is used for tree copying, and postorder for tree deletion. Level-order traversal visits nodes level by level using BFS. Understanding these traversals is fundamental for solving tree-related problems and forms the basis for more complex tree algorithms.
