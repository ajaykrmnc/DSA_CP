# LinkedList x Binary Tree

**Problem Statement:**
This section contains problems that involve both LinkedList and Binary Tree data structures or problems that convert between these two structures. Common problems include converting a binary tree to a doubly linked list, creating a binary tree from a linked list, finding paths in trees that can be represented as linked lists, or using linked list techniques to solve tree problems. These problems require understanding both data structures and their relationships, often involving tree traversals and linked list manipulations combined together.
