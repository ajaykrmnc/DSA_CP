# Debugging Checklist

## Problem Statement

Use this checklist when a divide-and-conquer solution gives wrong answers, double counts, misses cross-boundary cases, or is slower than expected.

## Code

```text
check base case
check split ranges
check cross-boundary contribution
check merge invariant
check whether mutation preserves required order/indexes
```
