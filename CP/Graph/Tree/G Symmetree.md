# G Symmetree

**Problem Statement:**
Given a rooted tree, determine if it's symmetric (i.e., the left and right subtrees are mirror images of each other).
This problem involves tree hashing techniques to efficiently compare subtree structures. You need to compute hash values
for each subtree and check if the tree has a symmetric structure by comparing hash values of corresponding subtrees.
The solution uses polynomial hashing or other tree hashing methods to assign unique identifiers to subtree structures
and then verify symmetry by comparing these hash values.
