# Secret Santa

**Problem Statement:**
There are n people participating in Secret Santa, where each person i wants to give a gift to person a[i]. However, some assignments might create conflicts or cycles. You need to determine the maximum number of people who can give gifts to their desired recipients while ensuring no conflicts occur. This is essentially a graph problem where you need to find the maximum matching or handle cycles in a directed graph. The solution involves detecting cycles, handling them appropriately, and maximizing the number of satisfied gift assignments using graph algorithms or greedy approaches.
