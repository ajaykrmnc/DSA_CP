# Shortest Paths

**Problem Statement:**
This section contains problems related to finding shortest paths in graphs and trees. Common algorithms include Dijkstra's algorithm for weighted graphs with non-negative edges, Bellman-Ford for graphs with negative edges, Floyd-Warshall for all-pairs shortest paths, and BFS for unweighted graphs. In trees, shortest path problems often involve finding distances between nodes, lowest common ancestor (LCA), and path queries. These problems require understanding of graph traversal, dynamic programming on trees, and efficient data structures for optimization.
