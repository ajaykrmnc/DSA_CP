# DFS

**Problem Statement:**
Depth-First Search (DFS) is a graph traversal algorithm that explores as far as possible along each branch before backtracking. It can be implemented recursively or using a stack data structure. DFS is useful for topological sorting, detecting cycles in graphs, finding strongly connected components, and solving maze problems. The algorithm visits a vertex, marks it as visited, then recursively visits all unvisited adjacent vertices. Time complexity is O(V + E) where V is vertices and E is edges. DFS is particularly effective for problems requiring complete exploration of paths or when you need to detect cycles.
