# DP With DFS

**Problem Statement:**
This section contains problems that combine Dynamic Programming with Depth-First Search on trees and graphs. These problems typically involve computing optimal values for subtrees, such as maximum path sums, counting paths with specific properties, or optimizing tree structures. Common patterns include tree DP where you compute values for each node based on its children, rerooting techniques to compute answers for all nodes, and using DFS to explore state spaces in DP problems. These techniques are essential for solving complex tree-based optimization problems.
