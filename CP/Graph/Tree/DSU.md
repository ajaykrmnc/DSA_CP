# DSU

**Problem Statement:**
This section contains problems using Disjoint Set Union (DSU) or Union-Find data structure. DSU efficiently handles dynamic
connectivity queries, determining if two elements are in the same connected component and merging components. Key operations
are Union (merge two sets) and Find (find representative of a set). Optimizations include path compression and union by rank/size
for nearly O(1) amortized time complexity. Common applications include Kruskal's MST algorithm, detecting cycles in graphs,
connected components, and solving connectivity problems in competitive programming.
