# Diameter

**Problem Statement:**
This section contains problems related to finding the diameter of trees and graphs. The diameter of a tree is the longest path
between any two nodes in the tree. Classic approaches include two DFS/BFS: first find the farthest node from any arbitrary node,
then find the farthest node from that node - the distance gives the diameter. Advanced problems involve tree DP where we calculate
the maximum path passing through each node. Applications include finding tree centers, optimal placement problems, and network
analysis. Time complexity is typically O(n) for trees using DFS/BFS or tree DP techniques.
