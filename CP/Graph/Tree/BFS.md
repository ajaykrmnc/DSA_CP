# BFS

**Problem Statement:**
Breadth-First Search (BFS) is a graph traversal algorithm that explores vertices level by level, starting from a source vertex. It uses a queue data structure to maintain the order of exploration. BFS is particularly useful for finding shortest paths in unweighted graphs, level-order traversal of trees, and solving problems that require exploring all nodes at the current depth before moving to nodes at the next depth. The algorithm has O(V + E) time complexity where V is vertices and E is edges. Common applications include shortest path problems, connected components, and bipartite graph checking.
