## How to Practice

1. Start with stack basics: `20`, `921`, `1249`.
2. Move to construction and scoring: `22`, `856`.
3. Learn substring/advanced validation: `32`, `678`, `2116`.
4. Finish with removal and swap problems: `301`, `1963`.
