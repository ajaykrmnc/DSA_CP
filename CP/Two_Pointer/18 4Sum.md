# 4Sum

**LeetCode:** [18. 4Sum](https://leetcode.com/problems/4sum/)  
**Difficulty:** Medium  
**Pattern:** Generalized k-sum  
**Tags:** Array, Two Pointers, Sorting

## Problem

Find all unique quadruplets whose sum equals the target.

## Approach

Sort first. Fix two positions and solve the remaining two-sum with inward pointers, using `long long` for sums and duplicate skipping.

## Solution

```cpp
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        sort(nums.begin(), nums.end());
        set<vector<int>> ans;
        int n= nums.size();
        for(int i = 0; i < n; i++) {
            for(int j = i + 1; j < n; j++) {
                int l = j + 1, r = n - 1;
                long long currSum = nums[i] + nums[j];
                while(l < r) {
                    long long temp = currSum + (long long)nums[l] + (long long)nums[r];
                    if(temp == (long long)target) {
                        ans.insert({nums[i], nums[j], nums[l], nums[r]});
                        l++;
                    }else {
                        if(temp < target) {
                            l++;
                        }else {
                            r--;
                        }
                    }
                }
            }
        }
        vector<vector<int>> result;
        for(auto &vec: ans) {
            result.push_back(vec);
        }
        return result;
    }
};
```
