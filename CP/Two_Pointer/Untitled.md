# Two Pointer Technique

**Problem Statement:**
This section contains problems that can be efficiently solved using the two-pointer technique. The two-pointer approach
involves using two pointers that move through the data structure (usually an array or string) to find a solution in
linear time. Common patterns include: finding pairs with a target sum in sorted arrays, removing duplicates, finding
subarrays with specific properties, and solving sliding window problems. This technique reduces time complexity from
O(n²) to O(n) for many problems by eliminating the need for nested loops.
