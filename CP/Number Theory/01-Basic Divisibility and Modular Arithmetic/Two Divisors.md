# Two Divisors

**Problem Statement:**
Given two integers a and b which are the two largest divisors of some number x (where 1 ≤ a < b < x), find the value of
x.
The problem requires understanding that if a and b are the two largest divisors of x, then either x = a*b (when gcd(a,b)
= 1)
or x = b*p where p is the smallest prime factor of b. This is a constructive mathematics problem involving number theory
concepts like divisors, prime factorization, and greatest common divisor. The key insight is analyzing the relationship
between the largest divisors and the original number.
