# Graph

Organized by graph problem type rather than source list.

## Problem Types

- `Traversal and Components` - cloning, connected components, reachability, and local graph scans.
- `Shortest Paths` - Dijkstra, Bellman-Ford, Floyd-Warshall, and path-score problems.
- `MST` - minimum spanning tree and critical edge problems.
- `Bipartite Graph` - two-coloring and partition checks.
- `Graph DP` - topological/order DP, path counting, state-compressed graph paths, and dependency propagation.
- `Tree Graph` - graph problems where the input structure is a tree.
- `Grid Graph` - graph traversal over matrices and grid-like states.
