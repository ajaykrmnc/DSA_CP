# Iroha and a grid

**Problem Statement:**
Given an H×W grid, find the number of paths from top-left (1,1) to bottom-right (H,W) where you can only move right or 
down. However, some rectangular regions in the grid are blocked and cannot be traversed. Use dynamic programming with 
inclusion-exclusion principle to handle blocked regions. Calculate total paths without restrictions, then subtract paths 
that go through blocked regions. The key insight is to use coordinate compression and careful handling of overlapping 
blocked regions to avoid double counting.
