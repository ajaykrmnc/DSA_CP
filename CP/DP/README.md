# Dynamic Programming

Organized by problem type rather than source list.

## Problem Types

- `Linear DP` - one-dimensional state transitions, including frog/vacation style problems and maximum subarray.
- `Knapsack DP` - 0/1 knapsack, subset sum, partition, rod cutting, and AtCoder knapsack variants.
- `LCS` - longest common subsequence and related string subsequence transformations.
- `LIS` - increasing subsequence variants, string chain, divisible subset, bitonic subsequence, and Flowers.
- `String DP` - edit distance, palindromic substring, and parenthesis DP.
- `Grid DP` - path counting and matrix-state DP.
- `DAG DP` - DP over directed acyclic graphs and topological order.
- `Tree DP` - DP over rooted or unrooted trees.
- `Bitmask DP` - subset states, matching, grouping, and team selection.
- `Game DP` - optimal play and take-away game states.
- `Probability DP` - expected value and probability-state problems.
- `Digit DP` - digit-by-digit counting states.
- `Prefix Sum DP` - DP optimized with prefix sums.
- `Interval DP` - matrix-chain style partitions, interval cuts, balloon bursting, and weighted interval scheduling.
- `Segment Tree DP` - DP combined with range query data structures.
- `Trie DP` - DP over trie/string-prefix states.
