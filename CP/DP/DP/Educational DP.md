# Educational DP

**Problem Statement:**
This section contains a collection of educational dynamic programming problems from AtCoder's DP contest. These problems cover fundamental DP concepts including basic DP, knapsack variations, longest common subsequence, longest increasing subsequence, edit distance, matrix chain multiplication, tree DP, digit DP, and probability DP. Each problem is designed to teach specific DP techniques and patterns that are commonly used in competitive programming. The problems range from beginner to advanced level and provide excellent practice for mastering dynamic programming concepts.
