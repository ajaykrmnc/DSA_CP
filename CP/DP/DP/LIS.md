# LIS

**Problem Statement:**
This section contains problems related to Longest Increasing Subsequence (LIS) and its variations. LIS problems involve finding
the longest subsequence in an array where elements are in strictly increasing order. The classic DP solution has O(n²) time
complexity, but can be optimized to O(n log n) using binary search with patience sorting technique. Variations include longest
bitonic subsequence, number of LIS, printing LIS, and maximum sum increasing subsequence. These problems demonstrate advanced DP
techniques and optimization strategies commonly used in competitive programming.
