# Tree DP

Organized by tree-DP transition type.

## Problem Types

- `Independent Set DP` - choose/non-choose states on a tree.
- `DFS State DP` - subtree states computed with DFS.
- `Rerooting DP` - recompute answers for every root using parent-child transitions.
- `Tree Cover DP` - cover/guard/camera-style states on trees.
