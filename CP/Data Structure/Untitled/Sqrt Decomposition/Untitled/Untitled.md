# Square Root Decomposition Implementation

**Problem Statement:**
This section contains implementations of Square Root Decomposition technique for solving range query problems. Square Root Decomposition divides an array of size n into √n blocks of size √n each, allowing range queries and updates to be processed in O(√n) time. This technique is useful for problems where segment trees might be overkill or when you need a simpler implementation. Common applications include range sum queries, range minimum/maximum queries, and range update problems with O(√n) query and update complexity.
