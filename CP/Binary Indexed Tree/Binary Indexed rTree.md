# Binary Indexed Tree

**Problem Statement:**
Binary Indexed Tree (BIT) or Fenwick Tree is a data structure that efficiently supports range sum queries and point updates in O(log n) time. Given an array, you need to handle two operations: update a single element and find the sum of elements in a range [L, R]. BIT uses the binary representation of indices to store partial sums in a tree-like structure. It's particularly useful for problems involving cumulative frequency tables, inversion counting, and dynamic range sum queries where both updates and queries need to be fast.
